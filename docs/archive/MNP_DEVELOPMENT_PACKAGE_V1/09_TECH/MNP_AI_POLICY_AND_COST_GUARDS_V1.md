# MNP AI POLICY AND COST GUARDS V1

## V1 core
No LLM required for CV baseline parsing, matching, feasibility, ranking, gaps or routes.

## Future optional AI
free-text enrichment, narrative explanation, CV rewriting, coach.

## Guards before enabling
feature flag, per-user quotas, rate limits, spend cap, caching where valid, model allowlist, telemetry, prompt-injection boundaries, no AI authority over deterministic ranking.

If AI is unavailable, BASIC career result must continue to work.
