# MNP ROUTE ENGINE V1

For selected target career produce:
TODAY → existing capital → reframe/prove → learn/practice/certify → first evidence → entry opportunity → target role → next step.

Scenarios:
SAFE: lowest transition cost / maximum reuse.
GROWTH: greater gap but better upside.
TRANSFORM: material change when justified.

Each RouteStep is structured, actionable, ordered, and can link to a gap or opportunity.
