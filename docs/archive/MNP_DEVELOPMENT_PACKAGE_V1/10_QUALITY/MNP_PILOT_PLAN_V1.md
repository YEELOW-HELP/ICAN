# MNP PILOT PLAN V1

## Goal
Validate recommendations before scale.

## Suggested pilot
100-300 adult users across target cohorts.

## Process
user flow → result → optional feedback → shadow expert review sample → 30/60/90-day outcome follow-up.

## Measure
recommendation usefulness, false blockers, missing careers, gap usefulness, route actionability, market accuracy, completion time, Career Card quality, actual actions.

No major weight change ships without Golden Dataset regression.
