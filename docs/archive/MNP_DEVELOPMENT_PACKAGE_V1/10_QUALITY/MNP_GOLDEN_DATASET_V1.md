# MNP GOLDEN DATASET V1

## Purpose
Calibrate and regression-test methodology.

## Initial target
20-50 synthetic/anonymized personas covering:
- experienced professional;
- unemployed;
- career changer;
- IDP;
- veteran civilian transition;
- return-to-Ukraine scenario;
- incomplete CV;
- no CV;
- strong credentials;
- legal blocker;
- high fit/low confidence;
- transferable skills across domains.

For each persona define:
input Career Card, expected known/unknown evidence, expected blockers, expected feasibility bands, acceptable TOP career set/ranges, unacceptable recommendations, explanation expectations.

Golden Dataset is versioned and never silently rewritten to make tests pass.
