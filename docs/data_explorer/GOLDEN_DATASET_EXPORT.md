# GOLDEN DATASET EXPORT — MNP DATA EXPLORER V1

The DATA EXPLORER turns hand-authored **Human Expected Results** into
machine-readable Golden fixtures for regression-testing the MNP engine
(brief §19, `MNP_GOLDEN_DATASET_V1`).

## Location — deliberately separate

```
evals/golden_data_explorer/
  schema.json                 generated by the exporter
  case_<persona_id>.json      one per hand-authored persona
```

This is a **sibling** of `evals/golden/`, not inside it, so the existing
AI-task schema test (`tests/test_golden_dataset_schema.py`, which
`rglob`s `evals/golden/**/*.json` against an AI-task schema) never
touches these deterministic Person↔Career cases. They have their own
schema and their own test (`tests/data_explorer/test_human_lab.py`).

## Fixture shape

```json
{
  "case_id": "de_<persona_id>",
  "dataset_version": "v1",
  "persona_id": "...",
  "person_profile_snapshot": { ...the full hand-authored Person Profile... },
  "expected_top_careers": [...],
  "acceptable_careers": [...],
  "unacceptable_careers": [...],
  "expected_feasibility": {"<career_code>": "ready_now|near_ready|reachable|long_transition|blocked"},
  "expected_transition_distance": {"<career_code>": "d0_same_career|...|d5_fundamental_retraining"},
  "expected_gaps": [{"skill_or_knowledge","gap_type","classification","action"}],
  "expected_unknowns": [...],
  "expected_blockers": [...],
  "rationale": "...",
  "methodology_version": "mnp_v1",
  "career_kb_version": "seed_alpha_v1",
  "source_data_versions": {"onet": "onet_31.0", "onet_work_values": "onet_30.2", "esco": "esco_v1.2.1", "crosswalk": "..."},
  "created_by": "<reviewer>",
  "created_at": "YYYY-MM-DD"
}
```

The person profile is **embedded** so a future eval runner needs nothing
else to reproduce the case.

## Rules

- **No LLM-generated expected result.** `created_by` records the human
  reviewer; the exporter refuses nothing automatically but the guide and
  review process forbid it.
- **Versioned, never silently rewritten.** To change an expectation, bump
  `dataset_version` (new folder) or add a new `case_id` — do not mutate a
  committed case to make a test pass (`MNP_GOLDEN_DATASET_V1`).
- `source_data_versions` pins the exact O*NET / ESCO / crosswalk releases
  the expectation was formed against, so a dataset bump is visible.

## Run

```bash
python -m data_explorer.cli golden
```

Reads every `*.person.yaml` + matching `*.expected.yaml` from
`data_explorer/human_lab/examples/` and `data/data_explorer/human_lab/`,
validates them against the MNP enums, and writes the fixtures.
