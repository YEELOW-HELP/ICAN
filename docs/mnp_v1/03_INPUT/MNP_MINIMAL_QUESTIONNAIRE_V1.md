# MNP MINIMAL QUESTIONNAIRE V1

## Principle
Do not ask what is already known. Questionnaire fills missing Career Intent and missing Career Capital.

## Entry modes
### With CV
Ask only missing/decision variables.

### Without CV
First collect minimal experience, education, skills and languages, then Career Intent.

## Required decision variables
1. Main goal: find work / change career / increase income / return to market / explore.
2. Desired work location/region.
3. Work format: onsite/hybrid/remote.
4. Target income where relevant; current income optional.
5. Time horizon.
6. Willingness to change profession.
7. Preferred work objects: people/data/technology/things/ideas.
8. Work environment/preferences.
9. Top work values.
10. Learning time/week.
11. Learning budget optional.
12. Willingness to gain qualification/license.
13. Willingness to accept lower entry level temporarily.
14. Excluded activities/careers.
15. Practical constraints relevant to work.

## Without-CV Career Capital minimum
- last/current role;
- years/periods of experience;
- main responsibilities;
- 5-15 skills/tools selected via searchable taxonomy;
- education;
- credentials where relevant;
- languages.

## UX
Short screens, progress indicator, structured controls, search/autocomplete, skip only for optional fields. No personality-test framing.

## Output
Normalized Career Card fields and CLAIMED evidence.
