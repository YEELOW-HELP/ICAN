# MNP FEASIBILITY RULES V1

## Status
READY_NOW / NEAR_READY / REACHABLE / LONG_TRANSITION / BLOCKED.

## Inputs
education, credentials, legal requirements, language, experience, time horizon, learning capacity, location and relevant hard constraints.

## BLOCKED
Only authoritative/high-confidence hard requirement can produce BLOCKED.

## Suggested interpretation
READY_NOW: no material mandatory gap.
NEAR_READY: small gap realistically closeable quickly.
REACHABLE: meaningful but realistic training/experience gap.
LONG_TRANSITION: substantial retraining/credential/time.
BLOCKED: objective mandatory condition not realistically satisfiable under current route/context.

Preference mismatch alone should not normally be BLOCKED.
