# MNP PRD V1

## V1 user journey
1. Landing/value proposition.
2. `Завантажити резюме` or `Пройти без резюме`.
3. Deterministic CV extraction or adaptive manual questionnaire.
4. Minimal Career Intent questions.
5. Immediate result.
6. Career Map: featured recommendations + modes + full 50-career catalog.
7. Career Compatibility view.
8. Career Card in cabinet.
9. Gap and Route.
10. Real opportunities where available.
11. User can edit Career Card and recalculate.

## Core screens
Landing, Upload/Manual Entry, Questionnaire, Processing, Results, Career Detail/Compatibility, Career Catalog, Career Card, Route, Opportunities, Settings/Data controls, Admin Career KB.

## V1 functional requirements
- auth/profile;
- file upload/extraction;
- Career Card CRUD/versioning;
- questionnaire;
- Career KB read/admin;
- deterministic matching;
- explainability;
- market snapshots;
- result history;
- analytics;
- privacy/delete.

## Non-functional
reproducibility, observability, security, auditability, accessibility, Ukrainian-first UI, responsive web.

## Out of V1 critical path
AI coach, guaranteed OCR, Lightcast, huge career catalog, mandatory paid upsell, complex personality test.
