# MNP DEFINITION OF DONE V1

A feature is Done when:
- spec acceptance criteria met;
- tests added/passing;
- deterministic behavior covered where applicable;
- permissions/privacy reviewed;
- analytics/audit events added where required;
- data provenance/versioning preserved;
- no hardcoded external IDs as MNP identity;
- error/empty/unknown states handled;
- documentation updated;
- CI green;
- founder gate respected for production release.
