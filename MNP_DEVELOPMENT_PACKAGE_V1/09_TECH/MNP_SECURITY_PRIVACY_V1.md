# MNP SECURITY AND PRIVACY V1

## Data classes
PII/account; CV/source documents; derived Career Card; analytics; public career/market data.

## Controls
- least privilege;
- encrypted transport/storage per platform capability;
- signed/private object access;
- file type/size validation;
- no macro execution;
- audit log for admin taxonomy changes;
- account/data deletion workflow;
- retention policy;
- backup/restore;
- secrets outside repository;
- rate limiting and abuse protection.

## GDPR-oriented requirements
purpose limitation, data minimization, transparency, access/export/delete mechanisms, processor inventory and retention rules.

Original CV may be retained for product function until user/account deletion under final retention policy; this must be made explicit in privacy notice.

Do not collect sensitive personal attributes merely to improve matching unless a separately justified feature requires them.
